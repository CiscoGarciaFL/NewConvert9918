# New Convert 9918 v0.1.0-beta.1

This is the first public packaging beta of the cross-platform New Convert 9918
rewrite. It is preview software intended for hands-on compatibility and package
testing before the signed stable release.

## Downloads

- Windows 10 version 1809 or newer, x64: use the `Setup.exe` installer or the
  `Portable.zip` archive.
- Linux x64 with glibc 2.34 or newer and X11: use the AppImage for a portable
  launch or the Debian package on Ubuntu 22.04 and compatible systems.
- macOS 13 or newer: use the `arm64` DMG on Apple Silicon or the `x86_64` DMG
  on Intel Macs.
- `SHA256SUMS.txt` contains the SHA-256 digest for every binary package.

All packages include the runtime files they need. Qt, CMake, a compiler, and a
developer environment are not required.

## Highlights

- Complete TMS9918A and F18A conversion modes with deterministic export.
- PNG, JPEG, BMP, GIF, TIFF, WebP, PCX, and supported retro-format input.
- TI Files, V9T9, raw, RLE, MSX Screen 2, CVPaint, PowerPaint, HGR, and PNG
  export paths with collision preflight and atomic writes.
- End-to-end desktop conversion workflow plus the `newconvert9918-cli`
  automation frontend.
- Screen, Character, and Sprite authoring workspaces, saved recipe data, and
  application preferences.

## Preview signing and trust prompts

These beta packages are not signed with a publicly trusted Windows or Apple
Developer ID certificate. The macOS application has only an ad-hoc signature.
The SHA-256 checksums detect download corruption, but unsigned packages do not
provide the publisher-identity assurance planned for the stable release.

- Windows may show Microsoft Defender SmartScreen. Confirm the downloaded
  filename and checksum, choose **More info**, verify the application name,
  and choose **Run anyway** only for this beta package.
- macOS may initially block the app. Control-click the app, choose **Open**,
  and confirm **Open**; if required, use the app-specific **Open Anyway** entry
  in Privacy & Security. Do not disable Gatekeeper system-wide.
- Linux AppImage: verify the checksum, run
  `chmod +x NewConvert9918-0.1.0-beta.1-Linux-x86_64.AppImage`, and launch it.
  Install the Debian package with
  `sudo apt install ./newconvert9918_0.1.0-beta.1_amd64.deb`.

## Verify checksums

On Linux or macOS, place `SHA256SUMS.txt` beside the downloads and run:

```shell
sha256sum --check SHA256SUMS.txt
```

On Windows PowerShell, compare a package with its entry in the checksum file:

```powershell
Get-FileHash .\NewConvert9918-0.1.0-beta.1-Windows-x64-Setup.exe -Algorithm SHA256
```

## Known limitations

- Packages are unsigned previews and may trigger platform trust warnings.
- Update discovery and automatic installation are not included. To update,
  download the next release manually; installers preserve the stable product
  identity and per-user settings.
- The Linux beta targets x64 X11 systems with glibc 2.34 or newer. Wayland is
  expected to work through Qt where available but is not yet a declared test
  target.
- Character and Sprite workspace data is saved in recipes, but CLI conversion
  of those editor-specific recipe types is deferred.

Please report package, launch, conversion, export, or compatibility problems at
<https://github.com/CiscoGarciaFL/NewConvert9918/issues> and include the asset
name, operating-system version, and relevant diagnostics.
