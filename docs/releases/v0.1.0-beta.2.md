# RetroVDP Studio v0.1.0-beta.2

**Do not install this release's Debian package.** It reused the AppImage runtime
tree as a system filesystem and could install `/usr/bin/qt.conf`, global Qt
plugins, QML modules, and bundled libraries. On Kubuntu this redirected the
Qt 5 SDDM greeter to incompatible Qt 6 plugins and removed the graphical login
screen after reboot. Remove `retrovdp-studio` before installing a corrected
release. The unsafe `.deb` asset has been withdrawn from GitHub. The AppImage
and non-Linux assets are not affected by this Debian path issue. The historical
`SHA256SUMS.txt` still includes the withdrawn filename, so verify a remaining
asset by selecting its individual checksum line rather than checking the whole
file set.

This corrective packaging beta supersedes `v0.1.0-beta.1`. It is preview
software intended for hands-on compatibility and package testing before the
signed stable release.

## Changes since beta.1

- The Windows desktop executable now uses the Windows GUI subsystem and no
  longer opens a console window when launched. The separate command-line
  executable remains a console application.
- The Debian package is published with normal read permissions, and the
  installation instructions now include a reliable terminal fallback for
  desktop package installers that fail to show an authorization prompt.
- Package publication now verifies the Windows executable subsystems, Debian
  archive mode, exact release asset set, DMG integrity, and SHA-256 checksums.

## Downloads

- Windows 10 version 1809 or newer, x64: use the `Setup.exe` installer or the
  `Portable.zip` archive.
- Linux x64 with glibc 2.34 or newer: use the AppImage for a portable launch or
  the Debian package on Ubuntu 22.04 and compatible systems. CI tests X11, and
  this beta has also been tested successfully on Kubuntu under Wayland.
- macOS 13 or newer: use the `arm64` DMG on Apple Silicon or the `x86_64` DMG
  on Intel Macs.
- `SHA256SUMS.txt` contains the SHA-256 digest for every binary package.

All packages include the runtime files they need. Qt, CMake, a compiler, and a
developer environment are not required.

## Highlights

- Complete TMS9918A and F18A conversion modes with deterministic export.
- PNG, JPEG, BMP, GIF, TIFF, WebP, PCX, and supported retro-format input.
- TI Files, V9T9, raw, RLE, MSX Screen 2, CVPaint, PowerPaint, HGR, and PNG
  export paths with collision preflight and atomic writes.
- End-to-end desktop conversion workflow plus the `retrovdp-cli`
  automation frontend.
- Screen, Character, and Sprite authoring workspaces, saved recipe data, and
  application preferences.

## Preview signing and trust prompts

These beta packages are not signed with a publicly trusted Windows or Apple
Developer ID certificate. The macOS application has only an ad-hoc signature.
The SHA-256 checksums detect download corruption, but unsigned packages do not
provide the publisher-identity assurance planned for the stable release.

- Windows may show Microsoft Defender SmartScreen. Confirm the downloaded
  filename and checksum, choose **More info**, verify the application name,
  and choose **Run anyway** only for this beta package.
- macOS may initially block the app. Control-click the app, choose **Open**,
  and confirm **Open**; if required, use the app-specific **Open Anyway** entry
  in Privacy & Security. Do not disable Gatekeeper system-wide.
- Linux AppImage: verify the checksum, run
  `chmod +x RetroVDPStudio-0.1.0-beta.2-Linux-x86_64.AppImage`, and launch it.
- Debian/Ubuntu: some desktop package installers fail silently when their
  authorization agent is unavailable. The reliable installation path is:

  ```shell
  chmod 0644 retrovdp-studio_0.1.0-beta.2_amd64.deb
  sudo apt install ./retrovdp-studio_0.1.0-beta.2_amd64.deb
  ```

  This changes only the downloaded package's read permissions and does not
  weaken system-wide security settings.

## Verify checksums

On Linux or macOS, place `SHA256SUMS.txt` beside the downloads and run:

```shell
sha256sum --check SHA256SUMS.txt
```

On Windows PowerShell, compare a package with its entry in the checksum file:

```powershell
Get-FileHash .\RetroVDPStudio-0.1.0-beta.2-Windows-x64-Setup.exe -Algorithm SHA256
```

## Known limitations

- Packages are unsigned previews and may trigger platform trust warnings.
- Update discovery and automatic installation are not included. To update,
  download the next release manually; installers preserve the stable product
  identity and per-user settings.
- The Linux beta targets x64 systems with glibc 2.34 or newer. X11 is covered
  by automated package testing, and Kubuntu under Wayland has passed hands-on
  testing. Other Wayland distributions and compositors remain provisional.
- Character and Sprite workspace data is saved in recipes, but CLI conversion
  of those editor-specific recipe types is deferred.

Please report package, launch, conversion, export, or compatibility problems at
<https://github.com/CiscoGarciaFL/retrovdp-studio/issues> and include the asset
name, operating-system version, and relevant diagnostics.
