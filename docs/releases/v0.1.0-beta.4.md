# RetroVDP Studio v0.1.0-beta.4

This is the first release under the RetroVDP Studio identity. It establishes a
target-independent graphics-workspace direction while retaining the proven
TMS9918A and F18A behavior from the earlier betas.

## Rebrand

- Renamed the application, repository, executable, command-line frontend,
  libraries, packages, desktop integration, and release artifacts.
- Repositioned the relationship with Convert9918 as an inspiration and
  historical behavioral reference.
- Updated the README, architecture, interface, packaging, release, and roadmap
  documentation for the broader graphics-workspace philosophy.
- Renamed Screen Image files as recipes rather than presenting them as a full
  project format.

## Upgrade notes

Beta.1 through beta.3 used the retired application and package identity. Remove
an installed earlier beta before installing beta.4. Portable ZIP, AppImage, and
DMG copies can be replaced normally.

On first launch, RetroVDP Studio imports earlier per-user settings when its new
settings store is empty. Existing version-1 recipe files remain readable; new
and resaved recipes use the `retrovdp-studio-recipe` identifier.
