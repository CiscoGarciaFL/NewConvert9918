# Contributing

Development is currently limited to maintainers and explicitly invited
contributors while the architecture, licensing, and output-parity baseline
are established.

Please use an issue to discuss a change before preparing a pull request.
Changes to conversion behavior must include a focused test and must not alter
existing golden outputs unless the behavior change is intentional and
documented.

Direct pushes to `main` will not be part of the project workflow. Changes will
be reviewed and merged through pull requests after all platform checks pass.
